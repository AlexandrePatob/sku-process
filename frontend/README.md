# Weduu — Processamento de SKU

Painel React + TypeScript.

## Executar

```sh
npm install
cp .env.example .env
npm run dev
```

Suba o backend, execute o ngrok e credencie sua URL pública na plataforma. Configure `VITE_API_BASE_URL` no `.env` e reinicie o Vite. (Por padrao esta a localhost:3000 para facilitar)

- `VITE_API_BASE_URL`: URL pública do backend.

Validação: `npm run build` e `npm run lint`.
